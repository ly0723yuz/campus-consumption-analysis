\# 校园消费数据分析系统



\## 一、项目简介



本项目是一个基于 Python 的校园消费数据分析系统，通过读取校园消费数据，对学生消费情况进行统计分析，并使用 Matplotlib 生成数据可视化图表。



项目适合用于学习 Python 数据分析、Pandas 数据处理以及 Matplotlib 数据可视化。



\## 二、使用技术



\* Python

\* Pandas

\* Matplotlib

\* CSV 数据文件



\## 三、项目功能



\### 1. 基础消费统计



统计校园消费数据中的：



\* 消费记录总数

\* 消费总金额

\* 平均每笔消费金额



\### 2. 学生消费统计



按照学生 ID 对消费金额进行汇总，分析不同学生的消费情况。



\### 3. 消费类型统计



按照消费类型统计消费金额，分析不同消费场景的消费情况。



\### 4. 最高消费学生分析



找出消费金额最高的学生，并显示其学生 ID 和消费金额。



\### 5. 数据可视化



使用 Matplotlib 将不同消费类型的消费金额生成柱状图，使消费结构更加直观。
